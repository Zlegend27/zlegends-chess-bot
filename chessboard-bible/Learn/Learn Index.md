# Learn

One note per concept, in the order you'll actually need them. Each maps to
an arc in [[Roadmap]] — you never have to learn something before the session
that uses it.

Most of these notes don't exist yet. That's fine and intentional: write each
one *after* you've used the concept, in your own words. A note written from
memory of doing it is worth ten copied from a datasheet.

[[Hall Effect Sensors]] is filled in as an example of the shape.

## Note template

```markdown
### What it is
Two sentences, no jargon.

### Why this project needs it
The specific job it does here.

### What confused me
The thing that wasn't obvious. This is the most valuable section.

### Gotchas
Anything that cost time.

### Reference
Links, datasheets, the video that made it click.
```
